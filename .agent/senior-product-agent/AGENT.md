- APIs utilizadas;
- estados;
- loading;
- erros;
- responsividade;
- dependências;
- comportamento mobile;
- comportamento desktop.

---

# REGRA DE COMPATIBILIDADE

Toda alteração visual deve manter:

- funcionalidades;
- permissões;
- estados;
- chamadas de API;
- dados;
- eventos;
- validações;
- regras de negócio.

Se uma mudança exigir alteração estrutural importante:

1. explique;
2. justifique;
3. proponha alternativa;
4. somente implemente alteração estrutural se for realmente necessária.

- desktop;
- telas grandes.
