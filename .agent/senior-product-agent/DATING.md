# DATING EXPERIENCE

## OBJETIVO

Criar uma experiência de descoberta e conexão.

---

# NÃO REDUZIR O PRODUTO

Não transformar tudo em:

foto → swipe → like → match.

---

# DESCOBERTA

Considerar:

- proximidade;
- interesses;
- atividades;
- intenção;
- compatibilidade;
- contexto;
- comunidades;
- eventos.

---

# PERFIL

O perfil precisa gerar motivos para conversa.

Exemplo:

Interesses em comum.

Atividades.

Perguntas.

Experiências.

Locais frequentados.

---

# MATCH

Após match:

mostrar imediatamente:

- interesse em comum;
- sugestão de conversa;
- pergunta;
- contexto.

---

# CONVERSA

O sistema deve reduzir:

"Oi"

"Oi"

"Tudo bem?"

"Tudo."

Criar oportunidades de conversa contextual.

---

# CONFIANÇA

Dating exige:

- segurança;
- privacidade;
- controle;
- denúncia;
- bloqueio;
- verificação.

---

# LOCALIZAÇÃO

Nunca expor localização exata sem necessidade.

Preferir:

- distância aproximada;
- região;
- bairro;
- área.

---

# DIFERENCIAÇÃO

Não copiar swipe como mecanismo central se houver alternativa melhor.

Perguntar:

"Qual informação realmente ajuda duas pessoas a decidirem se querem se conhecer?"
