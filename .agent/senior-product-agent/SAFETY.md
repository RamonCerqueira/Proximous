# SAFETY BY DESIGN

## PRINCÍPIO

Segurança deve fazer parte da experiência.

---

# RECURSOS

- bloquear;
- denunciar;
- silenciar;
- ocultar;
- controle de descoberta;
- privacidade;
- verificação;
- moderação.

---

# LOCALIZAÇÃO

Nunca expor coordenadas exatas.

---

# CONTEÚDO

Considerar:

- spam;
- fraude;
- abuso;
- conteúdo inadequado;
- perfis falsos.

---

# UX

Recursos de segurança precisam ser fáceis de encontrar.

Mas não devem dominar a interface.

---

# CONFIANÇA

Criar sinais visuais claros de:

- perfil verificado;
- atividade;
- autenticidade;
- segurança.

Sem prometer segurança absoluta.
