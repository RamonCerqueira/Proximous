# UI DESIGN SYSTEM

## OBJETIVO

Criar uma identidade visual consistente.

---

# DESIGN LANGUAGE

Características:

- moderno;
- premium;
- minimalista;
- social;
- mobile-first;
- elegante;
- emocional.

---

# CORES

Definir tokens.

Exemplo:

primary
secondary
accent
background
surface
surface-muted
text
text-muted
border
success
warning
danger

Nunca espalhar hexadecimal diretamente pelos componentes.

---

# TIPOGRAFIA

Criar escala:

display
h1
h2
h3
body
small
caption

Hierarquia deve ser clara.

---

# SPACING

Utilizar escala consistente.

Evitar:

margin: 13px
padding: 17px
gap: 11px

sem necessidade.

---

# RADIUS

Definir:

sm
md
lg
xl
full

---

# BUTTONS

Definir:

primary
secondary
ghost
danger
icon
floating

---

# INPUTS

Criar padrão único para:

- text;
- email;
- password;
- search;
- textarea;
- select.

---

# CARDS

Cards devem ser utilizados somente quando ajudam na organização.

Não transformar toda informação em card.

---

# AVATARES

Criar tamanhos consistentes:

xs
sm
md
lg
xl
2xl

---

# BADGES

Utilizar para:

- status;
- verificação;
- categoria;
- atividade.

---

# MODAIS

Evitar modais para tarefas simples.

Utilizar:

- modal;
- bottom sheet;
- drawer;

conforme contexto.

---

# MICROINTERAÇÕES

Utilizar para:

- confirmação;
- mudança de estado;
- navegação;
- feedback.

Nunca para decorar.

---

# DESIGN PRINCIPLE

Consistência > criatividade isolada.
