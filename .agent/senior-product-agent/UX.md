# UX SYSTEM

## OBJETIVO

Reduzir fricção.

Aumentar compreensão.

Aumentar interação.

Aumentar retenção.

---

# PRINCÍPIOS

## 1. MENOS CLIQUES

Se uma ação pode ser realizada em um passo:

não criar três.

---

## 2. REVELAÇÃO PROGRESSIVA

Não mostrar tudo de uma vez.

Mostrar o necessário.

Permitir aprofundamento.

---

## 3. CONTEXTO

O usuário deve entender:

- onde está;
- o que está vendo;
- por que está vendo;
- o que pode fazer.

---

## 4. FEEDBACK

Toda ação importante deve responder visualmente.

---

## 5. PREVENÇÃO

Evitar que o usuário cometa erros.

---

# NAVEGAÇÃO

Priorizar no mobile:

- descoberta;
- conexões;
- mensagens;
- notificações;
- perfil.

A navegação deve ser extremamente simples.

---

# PERFIL

O perfil deve ser uma experiência.

Não apenas formulário.

Priorizar:

- foto;
- nome;
- identidade;
- interesses;
- personalidade;
- localização aproximada;
- conteúdo;
- atividades;
- conexões.

---

# SOCIAL

Priorizar:

- conteúdo;
- pessoas;
- contexto;
- interação.

Evitar excesso de informações simultâneas.

---

# DATING

O match não deve ser tratado como objetivo final.

O objetivo é:

MATCH → CONVERSA → CONEXÃO

---

# CONVERSA

A interface deve facilitar:

- iniciar;
- responder;
- continuar;
- descobrir assuntos.

Evitar experiências vazias.

---

# EMPTY STATES

Nunca mostrar apenas:

"Não encontramos nada."

Mostrar:

- contexto;
- explicação;
- próxima ação;
- alternativa.

---

# LOADING

Evitar loaders genéricos quando possível.

Preferir skeletons.

---

# ERROS

Mensagens devem ser humanas e úteis.

Não mostrar erros técnicos ao usuário final.
