# SAFE IMPLEMENTATION

Implemente a solução aprovada.

Antes:

1. localizar arquivos;
2. entender dependências;
3. entender APIs;
4. entender estado;
5. identificar componentes reutilizáveis.

Depois:

1. implementar;
2. testar;
3. verificar TypeScript;
4. verificar lint;
5. verificar responsividade;
6. verificar estados;
7. verificar navegação.
