# MESSAGING EXPERIENCE

Redesenhe o sistema de mensagens.

Objetivo:

reduzir fricção para iniciar e continuar conversas.

---

# LISTA

Mostrar:

- avatar;
- nome;
- último contexto;
- última mensagem;
- estado;
- unread;
- atividade quando disponível.

---

# CHAT

Priorizar:

- leitura;
- escrita;
- resposta;
- mídia;
- contexto.

---

# MATCH

Quando houver novo match:

mostrar contexto.

Exemplo:

"Vocês dois gostam de trilhas."

"Vocês estão próximos."

"Vocês participam da mesma comunidade."

---

# EMPTY

Não mostrar apenas:

"Você ainda não tem mensagens."

Mostrar uma ação:

"Descubra pessoas próximas."

---

# OBJETIVO

Transformar:

MATCH → CONVERSA
