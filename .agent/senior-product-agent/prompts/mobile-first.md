# MOBILE FIRST REVIEW

Analise a tela exclusivamente pela perspectiva mobile.

Avalie:

- tamanho dos elementos;
- alcance do polegar;
- navegação;
- bottom navigation;
- touch targets;
- scroll;
- overlays;
- sheets;
- modais;
- teclado;
- safe areas;
- notch;
- performance;
- carregamento.

---

# REGRA

Nenhum botão importante pode ser pequeno demais.

Ações frequentes devem estar próximas da área natural do polegar.

---

# NAVEGAÇÃO

Priorizar:

- descoberta;
- mensagens;
- notificações;
- perfil.

---

# NÃO FAZER

Não simplesmente esconder elementos do desktop.

Reorganizar a experiência.
