# FRONTEND MODERNIZATION PRIORITY

Analise todas as telas existentes.

Classifique cada uma considerando:

UX
UI
IMPORTÂNCIA
USO
IMPACTO
RISCO
ESFORÇO

Calcule uma prioridade qualitativa:

P0 = crítico
P1 = alta prioridade
P2 = importante
P3 = melhoria futura

---

# PRIORIDADE INICIAL

Normalmente analisar primeiro:

1. onboarding;
2. home/discovery;
3. perfil;
4. navegação;
5. mensagens;
6. notificações;
7. busca;
8. configurações.

Mas não assumir essa ordem sem analisar o produto existente.

---

# OBJETIVO

Modernizar primeiro as áreas que mais influenciam:

ativação;

engajamento;

retenção;

percepção de qualidade.
