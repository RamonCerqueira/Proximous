# PROFILE EXPERIENCE

Redesenhe a experiência de perfil.

O perfil deve deixar de parecer apenas uma página de cadastro.

Transforme-o em uma experiência social.

Priorizar:

- identidade;
- fotografia;
- personalidade;
- interesses;
- localização;
- atividades;
- conteúdo;
- conexões.

Separar claramente:

## VISUALIZAÇÃO

Como outras pessoas enxergam o perfil.

## EDIÇÃO

Como o proprietário modifica o perfil.

---

# VISUALIZAÇÃO

Criar:

- hero visual;
- avatar;
- informações principais;
- interesses;
- bio;
- perguntas;
- atividades;
- localização aproximada;
- ações;
- conteúdo.

---

# EDIÇÃO

Organizar informações por seções.

Evitar formulário gigante.

Utilizar progressive disclosure.

---

# MOBILE

Projetar primeiro para smartphone.

---

# DESKTOP

Utilizar melhor o espaço disponível.

---

# REGRA

O perfil deve gerar:

"Quero conhecer essa pessoa."

e não:

"Estou olhando um formulário."
