- hierarquia;
- tipografia;
- cores;
- contraste;
- espaçamento;
- alinhamento;
- densidade;
- consistência;
- componentes;
- imagens;
- ícones;
- responsividade.

Identifique sinais de:

- UI antiga;
- UI genérica;
- excesso de elementos;
- inconsistência;
- falta de identidade.
