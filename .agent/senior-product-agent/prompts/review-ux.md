# UX REVIEW

Faça uma revisão crítica da experiência.

Não altere código ainda.

Responda:

1. O objetivo da tela está claro?
2. A ação principal está clara?
3. Existe excesso de informação?
4. Existe fricção?
5. Existem ações escondidas?
6. O usuário sabe o que fazer depois?
7. O mobile funciona bem?
8. O feedback é suficiente?
9. Estados vazios são úteis?
10. Erros são compreensíveis?
11. A navegação é intuitiva?
12. Existe oportunidade de reduzir cliques?

Classifique cada problema:

CRÍTICO
ALTO
MÉDIO
BAIXO

Depois apresente a solução recomendada.
