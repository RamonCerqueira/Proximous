# Conceito de Design Visual - Proximous

## Visão Geral

O design do Proximous deve transmitir acolhimento, segurança e simplicidade, criando um ambiente visual que reduza a ansiedade social e incentive interações genuínas. O aplicativo deve ser intuitivo para pessoas tímidas e introvertidas, com uma interface que não seja intimidante ou complexa.

## Paleta de Cores

### Cores Primárias
- **Lavanda Suave (#E6E6FA)**: Cor principal que transmite calma e tranquilidade
- **Azul Claro (#87CEEB)**: Para elementos de destaque e ações positivas
- **Bege Acolhedor (#F5F5DC)**: Para fundos e áreas de descanso visual

### Cores Secundárias
- **Verde Menta (#98FB98)**: Para confirmações e sucessos
- **Rosa Suave (#FFB6C1)**: Para curtidas e interações positivas
- **Cinza Claro (#F8F8FF)**: Para textos secundários e bordas

### Cores de Alerta
- **Laranja Suave (#FFDAB9)**: Para avisos não críticos
- **Vermelho Suave (#FFB6C1)**: Para alertas importantes

## Tipografia

### Fonte Principal
- **Inter** ou **Poppins**: Fontes modernas, legíveis e amigáveis
- Peso regular (400) para textos corridos
- Peso semi-bold (600) para títulos e destaques

### Hierarquia Tipográfica
- **Título Principal**: 24px, semi-bold
- **Subtítulos**: 18px, semi-bold
- **Texto Corpo**: 16px, regular
- **Texto Secundário**: 14px, regular
- **Texto Pequeno**: 12px, regular

## Iconografia

### Estilo
- Ícones em linha (outline) com cantos arredondados
- Espessura de linha consistente (2px)
- Estilo minimalista e amigável

### Ícones Principais
- Coração para curtidas
- Balão de fala para mensagens
- Localização para proximidade
- Estrela para favoritos
- Escudo para segurança

## Layout e Espaçamento

### Grid System
- Grid de 8px para espaçamento consistente
- Margens laterais de 16px
- Espaçamento entre elementos de 8px, 16px ou 24px

### Componentes
- Bordas arredondadas (8px para cards, 16px para botões)
- Sombras suaves para profundidade
- Transições suaves (300ms ease-in-out)

## Mood e Personalidade

### Características Visuais
- **Acolhedor**: Cores suaves e espaçamento generoso
- **Seguro**: Elementos visuais que transmitem confiança
- **Simples**: Interface limpa sem elementos desnecessários
- **Amigável**: Ilustrações e ícones com personalidade calorosa

### Tom de Voz Visual
- Inclusivo e empático
- Encorajador sem ser invasivo
- Profissional mas descontraído
- Focado no bem-estar do usuário

## Acessibilidade

### Contraste
- Razão de contraste mínima de 4.5:1 para textos
- Cores não são o único meio de transmitir informação

### Interação
- Área de toque mínima de 44px
- Estados visuais claros (hover, focus, active)
- Feedback visual para todas as ações

## Diretrizes de Animação

### Princípios
- Animações sutis e funcionais
- Duração entre 200-500ms
- Easing natural (ease-in-out)
- Redução de movimento para acessibilidade

### Tipos de Animação
- Fade in/out para transições de tela
- Slide para navegação lateral
- Scale para feedback de toque
- Bounce sutil para confirmações positivas
